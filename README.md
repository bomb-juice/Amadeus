# Amadeus UI
![UI demo](https://github.com/user-attachments/assets/eb103ca9-d036-4a1b-829c-8cada6a4f050)

A web app chatbot UI based on Amadeus from Steins;Gate 0. When you speak to Amadeus, don't be surprised when you're met with a little sass and tsundere (it's kind of the point). The chatbot works by using pronoun swaps, rules, fallbacks, and browser memory. If you want to erase Amadeus's memory, then just say "reset memory" or "forget me".

## 📁 File Structure
* 'index.html' - main webpage and UI layout
* 'style.css' - stylesheet for layouts, colors, and fonts
* 'script.js' - logic for actions/replies & vfx
* 'kurisu.py' - OUTDATED AI development/tests. Check 'script.js' for the updated and working script.
